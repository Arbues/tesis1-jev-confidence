## 4. Datos duros que NO deben re-descubrirse

**Jev (TypeSafe System One, `jev-1.13.0`, 18-sep-2026).** Tres primitivos: `choice` (≤255 opciones, devuelve
opción + `probabilities` + `confidence`), `score` (2–10 niveles ordinales, + `legend`), `noul` (0.0–1.0,
**sin** campo `confidence`). Mecánica: *readout* de logits en la posición de cada etiqueta + softmax **solo
sobre etiquetas permitidas** → `output_tokens = 0` por construcción. Estado compartido, preguntas aisladas:
**no hay distribución conjunta**. `confidence` en choice/score **no** es la probabilidad ganadora: es
concentración, `(n·p_max − 1)/(n − 1)`. TypeSafe **no ha publicado ni un ECE ni los pesos ni la pérdida**.

**RLCD.** Ruido gaussiano de media cero en los logits (σ 1.0 → 0.3) + regla de puntuación **estrictamente
propia** (log con suelo −9.21 + 0.75·spherical; RPS para `score` ordinal) + REINFORCE con baseline de grupo
+ temperatura post-hoc. En teoría reportar honestamente es la única estrategia óptima; en la práctica
**ningún proyecto lo logró**. Análisis cerrado (26-sep): el término RL ≈ gradiente de la cross-entropy
suavizada → sobre-confianza (LakoreAI/sev).

**Laya** (`NandhaKishorM/laya`, Apache-2.0, **421M** = ModernBERT-large + cabeza que puntúa un token `[MASK]`).
Única implementación que publica el bucle RLCD completo. Encoder congelable → features cacheadas.
Su `confidence` = `1 − entropía normalizada` (choice/score) y `max(p,1−p)` para `noul` — **¡no la fórmula de Jev!**

**Contradicción de calibración de Laya (reconciliada):** el model card dice *over-confident* (macro-ECE sobre
sus suites, 0.466 → 0.081 con refit); arXiv:2609.33843 mide el checkpoint **tal cual se distribuye** y lo
encuentra **sub-confíado** (ECE 0.214; T=0.469 → 0.037). Miden artefactos distintos.

**El dato central del eje:** el ecosistema abierto **refutó empíricamente la premisa de Jev**. Donde hay
calibración, vino de un **ajuste de temperatura post-hoc**, no del objetivo de entrenamiento. El mismo campo
`confidence` tiene **definiciones incompatibles** (Jev, Laya entropía, Laya `noul`, `answer_confidence` =
p_max, `act_probability`, prior aprendido) y **cero estudios de transferencia de umbrales entre ellas**.

**Huecos ya ocupados (no volver a proponerlos):** por qué RLCD no calibra (arXiv:2609.38850) · **ablación de
RLCD** (LakoreAI/sev) · **cartografía del ecosistema** (arXiv:2609.30216) · coherencia/negación
(arXiv:2609.33209) · sesgo nombre↔definición (arXiv:2609.26758) · metrología **dentro** de una definición
(UCLA) · calibración de Laya (arXiv:2609.33843). **Lo único abierto que exige anotación manual (prohibida) es
el ground truth humano con kappa.**
